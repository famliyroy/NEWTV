# 开发计划与任务分解（WBS）

> 依赖：`02-客户端打包方案.md`（远程后端模式）
> 估算口径：**人日**（1 人日 = 6 小时有效产出），不含缓冲；每里程碑末留 15%
> 范围：v1.0 双端客户端（Windows EXE + Android APK），**不含任何后端改动**

T-0.1(0.5) → T-1.1(1) → T-1.2(1) → T-1.3(1.5) → T-1.5(1) → T-1.7(0.5)

约 **9 人日**，占总工作量 45%。含义：

- **最快 4–5 人日**就能拿到第一个"能登录能播"的 EXE，可以先自己用起来，再补托盘/更新/文档。

## 5. GitHub 文档与发布

### 5.1 仓库结构

```
README.md                  # 定位 / 截图 / 下载 / 5 分钟上手 / 署名与免责
docs/
├─ 01-逆向分析报告.md
├─ 02-客户端打包方案.md
├─ 03-开发计划与任务分解.md
├─ 04-风险登记与合规审查.md
├─ install.md              # 安装与首次配置（重点讲"填服务器地址"）
├─ usage.md                # 桌面/手机功能差异、扫码配对、清除缓存
├─ faq.md                  # 为什么装完要填地址 / 登录不上 / 视频不播 / 更新
├─ build.md                # 本地构建（Rust / Android SDK 前置）
├─ signing.md              # 签名与密钥管理（流程，无密钥值）
└─ archive/                # 已作废的内嵌引擎方案（保留可追溯）
```

### 5.2 README 首屏

1. 一句话定位：**「MoonTVPlus 的 Windows / Android 客户端壳，需配合自建服务端使用」**
2. 两张截图（桌面 + 手机）
3. 下载 Latest Release
4. 5 分钟上手：装 → 填地址 → 登录
5. 与上游的关系 + 上游署名链接
6. 免责声明 + 许可说明

> 措辞要点：必须让用户第一眼明白"**这不是一个自带资源的播放器**，需要自己的服务端"——否则会收到大量"装完是空的"反馈。

### 5.3 发布流程

```
1. 版本号三处一致（tauri.conf.json / android versionCode / package.json）
2. CHANGELOG：新增 / 修复 / 已知问题
3. git tag vX.Y.Z → push
4. CI 出桌面（通用版）+ Android（arm64/v7a）
5. 跑验收清单（§6）
6. 发布 Release + SHA256SUMS
7. 私有版单独构建，不进公开 Release
```

### 5.4 产物矩阵

| 产物 | 命名 | 公开 |
| --- | --- | --- |
| 桌面安装包 | `MoonTVPlus-Setup-x.y.z.exe` | ✅ |
| Android arm64 | `MoonTVPlus-x.y.z-arm64-v8a.apk` | ✅ |
| Android v7a | `MoonTVPlus-x.y.z-armeabi-v7a.apk` | ✅ |
| 校验文件 | `SHA256SUMS.txt` | ✅ |
| 私有版（含默认地址） | 不公开命名 | ❌ 仅自用 |

## 6. 验收清单

### 桌面

- [ ] 干净 Win11 双击安装即用；Win10 21H2 同样通过
- [ ] 未装 WebView2 时给出安装引导，不白屏
- [ ] 首次启动进设置页，填入地址后可打开登录页
- [ ] 登录后能浏览、搜索、播放（含全屏）
- [ ] **彻底退出再启动，仍是登录态**
- [ ] 点源站详情跳系统浏览器，壳不被劫持
- [ ] 关窗进托盘；托盘退出后无残留进程
- [ ] 清除缓存后可切换账号
- [ ] 断网/域名错误时有可读提示
- [ ] 通用版安装包内 `strings` 搜不到任何真实域名

### Android

- [ ] Android 8 / 12 / 14 真机安装成功
- [ ] 首启进配置页，手输地址成功进入
- [ ] 扫码导入配置成功
- [ ] 返回键行为正确，根页面二次确认退出
- [ ] 全屏播放自动横屏，退出恢复竖屏
- [ ] 杀进程重开仍登录
- [ ] 下载进通知栏并可打开
- [ ] 清缓存后能换号

### 仓库

- [ ] `clone` 后按 `docs/build.md` 能本地构建
- [ ] CI 绿灯，Release 产物可下载
- [ ] 文档无死链，署名与许可齐全
- [ ] 仓库无密钥、无 keystore、无真实域名

## 7. 范围边界（明确不做）

| 不做 | 原因 |
| --- | --- |
| 修改上游任何代码 | 后端保持纯净，升级零成本 |
| 客户端内嵌后端 / 离线播放 | 已有服务器，无需重复投入 |
| 客户端自绘播放器 | 上游播放器功能完整，重写等于重做项目 |
| 账号体系 / 付费 / 会员 | 与上游定位冲突，且触碰许可证 NC 条款 |
| 应用商店上架 | 过审无望，且牵连开发者账号 |
| TV 版 | 上游已有 `apps/android-tv`，有需求时直接复用 |
