# 本地构建环境备忘（macOS）

> 记录本机为跑通构建所做的环境处理，换机器或重装时可对照。

## 工具链位置（刻意选择）

| 组件 | 位置 | 原因 |
| --- | --- | --- |
| Flutter SDK | `~/WorkBuddy/.tooling/flutter`（项目外） | 项目路径含中文 `开发`，Gradle 经 `Properties.load(InputStream)`（硬编码 ISO-8859-1）读 `local.properties` 会把 SDK 路径搞成乱码。SDK 放在纯 ASCII 路径可彻底绕开。`settings.gradle.kts` 已改为 UTF-8 读取（双保险）。 |
| Dart 依赖缓存 | 项目内 `.tooling/pub-cache` | 沙箱禁止写默认 `~/.pub-cache`，用项目内缓存避免污染用户目录。构建时设 `PUB_CACHE` 指向它。 |
| JDK | `/opt/homebrew/opt/openjdk@17`（brew openjdk@17） | Gradle 需要；系统未设 `JAVA_HOME`，构建时显式导出。 |
| Android SDK | `~/Library/Android/sdk` | 本机已有 platform-34 / build-tools 34；构建按需补装了 35、36、build-tools 36、NDK 28.2.13676358、cmake 3.22.1。 |

## 网络注意事项（本机实测）

1. **沙箱代理**：执行环境注入的 `HTTP(S)_PROXY=127.0.0.1:xxxx` 会让 `flutter test` 的 flutter_tester WebSocket 连不上（全部测试报 `Invalid WebSocket upgrade request`）。跑测试/构建前 `env -u` 清掉六个代理变量。
2. **Java 下载走 IPv6 被拒**：sdkmanager/Gradle 访问 dl.google.com 大文件经常 `Connection refused`（IPv6 路由问题），curl 正常。处理：
   - `export JAVA_TOOL_OPTIONS="-Djava.net.preferIPv4Stack=true"` 可解决 NDK 安装；
   - platform / build-tools 若仍失败，用 curl 直接下 zip 手工解压进 SDK（见下）。
3. dl.google.com 的 maven 仓库（AGP/依赖）是通的，只有大文件 zip 下载容易断。

## SDK 组件手工安装法（sdkmanager 拉不动时）

```bash
# 1. 从 repository2-3.xml 查包名
curl -s https://dl.google.com/android/repository/repository2-3.xml | grep -oE 'platform-36_r[0-9]+\.zip'

# 2. curl 下载并解压
curl -fL https://dl.google.com/android/repository/platform-36_r02.zip -o /tmp/p36.zip
unzip -q /tmp/p36.zip -d /tmp/p36 && mv /tmp/p36/android-36 "$ANDROID_HOME/platforms/android-36"

# 3. 从相邻版本生成 package.xml（sdkmanager 列表用，AGP 不强制）
sed -e 's/<api-level>34</<api-level>36</g' "$ANDROID_HOME/platforms/android-34/package.xml" \
  > "$ANDROID_HOME/platforms/android-36/package.xml"
```

## 构建命令（本机一次性跑通）

```bash
export PUB_CACHE="$PWD/../.tooling/pub-cache"   # 或项目 .tooling/pub-cache 绝对路径
export ANDROID_HOME="$HOME/Library/Android/sdk"
export JAVA_HOME="/opt/homebrew/opt/openjdk@17"
export JAVA_TOOL_OPTIONS="-Djava.net.preferIPv4Stack=true"
env -u HTTPS_PROXY -u HTTP_PROXY -u ALL_PROXY -u https_proxy -u http_proxy -u all_proxy \
  "$HOME/WorkBuddy/.tooling/flutter/bin/flutter" build apk --debug
```

注意：移动 Flutter SDK 后必须重跑 `flutter pub get`（`package_config.json` 里存了 SDK 绝对路径）。

## 已知的沙箱残留

- `~/Library/Android/sdk` 下曾产生 `*.backup` / `36.0.0.backup` 等中断安装残留，已移入系统废纸篓。
- 沙箱内启动过的 Gradle Daemon 会带沙箱 profile（拒绝写 `~/Library`），异常时 `pkill -f GradleDaemon` 后重建。
