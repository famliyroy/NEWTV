### 学什么 / 不学什么

**要学**（本项目的设计骨架）：
1. **玻璃拟态的分层策略**——海报做背景模糊，信息卡浮在上层，暗色下不死黑
2. **播放器控制层的"两段式"**——默认极简（只有进度条 + 弹幕开关），点击才展开完整控制
3. **详情页的横向剧集轨道**——集数多时横向滚动而非分页
4. **弹幕的轨迹记忆与防遮挡**——同一用户/同一色系弹幕不重叠；顶部/底部弹幕避开字幕区
5. **多端自适应**——桌面鼠标悬停态 + 移动端手势 + TV 焦点态，三套输入都要能用

**不要学**：
1. 它的**播放内核体系**（Erika/FVP/libmpv 三选）——我们只需要一个能播 HLS 的内核，过度抽象是负担
2. 它的**媒体库/插件系统**——我们对接的是 MoonTVPlus 后端，不是 Emby/SMB
3. 它的**具体配色数值**——照抄会显得"像换皮"，我们按第 1 节自建 token

## 1. 设计语言（Design Tokens）

> 玻璃拟态最常见的失败是"亮色下糊成一片灰、暗色下糊成一片黑"。所以先定 token，再谈组件。

### 1.1 色彩

```dart
// 品牌主色：取自 MoonTVPlus 的青蓝调，避免和参考项目撞脸
primary        #3B82F6   // 主操作、进度条已播段
primaryDim     #2563EB   // 按下态
accent         #22D3EE   // 弹幕开关激活、强调数据

// 亮色主题
bgBase         #F5F7FA   // 页面底色（不用纯白，减少刺眼）
surface        rgba(255,255,255,0.72)  // 玻璃卡片
surfaceSolid   #FFFFFF   // 需要实底的地方（表单、菜单）
textPrimary    #0F172A
textSecondary  #64748B
divider        rgba(15,23,42,0.08)

// 暗色主题
bgBase         #0B0F14   // 不用纯黑，保留海报层次的余地
surface        rgba(22,28,36,0.66)
surfaceSolid   #161C24
textPrimary    #E8EDF3
textSecondary  #94A3B8
divider        rgba(232,237,243,0.10)

// 语义
success #22C55E   warning #F59E0B   danger #EF4444
// 注意：本 App 不显示股票式涨跌，勿套用红涨绿跌
```

**硬性规则**
- 玻璃层**必须同时具备**：`BackdropFilter(blur 24)` + 半透明填充 + 1px 内描边（`rgba(255,255,255,0.14)` 暗色下 / `rgba(255,255,255,0.6)` 亮色下）。缺任一，玻璃感就塌成灰块。
- 玻璃层**最多叠 2 层**。第 3 层开始必须用实底，否则内容不可读。
- 任何文字压在模糊背景上，必须满足对比度 ≥ 4.5:1；达不到就加一层 `surfaceSolid` 底。

### 1.2 圆角 / 间距 / 层级

```
radius: sm 8 · md 14 · lg 20 · pill 999
spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48
elevation（玻璃体系不用阴影，用 blur 强度代替）:
  L0 页面底  blur 0
  L1 卡片    blur 24  + 描边 0.14
  L2 浮层    blur 40  + 描边 0.18 + 外阴影 (0,8,32, rgba(0,0,0,0.28)) 仅暗色
  L3 播放器控制层 blur 60
```

### 1.3 字体

- 中文：系统字体优先（`PingFang SC` / `Microsoft YaHei` / `Noto Sans CJK SC`），**不内嵌中文字体**（否则包体 +8MB，且可读性无提升）
- 数字与英文：`Inter`（可选内嵌，仅拉丁子集，约 120KB）
- 字号阶梯：`display 32 / title 20 / body 15 / caption 13 / micro 11`
- 弹幕默认字号 **25**（与上游设置默认值一致），可 18~40 调节

### 1.4 图标

- 使用 **Material Symbols**（有 Flutter 官方包），不引入参考项目的 Hugeicons（避免许可与风格混淆）
- 播放器核心图标（播放/暂停/音量/全屏/弹幕）**必须自绘 SVG**，保证 24/32/48 三档清晰

## 2. 页面清单与信息架构

```
启动
 ├─ 〔首次启动〕服务器配置页  ──→ 登录页 ──→ 首页
 └─ 〔已配置〕   启动检查 ──→ 首页

底部导航（移动端）/ 左侧导航栏（桌面端，宽 ≥ 900dp）
 ├─ 首页        Home
 ├─ 发现        Discover（分类/榜单/推荐）
 ├─ 追番        Schedule（新番表）
 ├─ 我的        Library（收藏 / 历史 / 下载）
 └─ 设置        Settings

独立页（push）
 ├─ 搜索页 / 搜索结果
 ├─ 详情页
 ├─ 播放页（全屏，横屏）
 └─ 弹幕设置面板（bottom sheet / 侧滑）
```

**导航形态决策**
- 移动端：底部 `NavigationBar`（Material 3），4~5 项，图标 + 短标签
- 桌面端 ≥900dp：左侧 `NavigationRail` 展开态（图标 + 文字），内容区最大宽 1600dp 居中，两侧留白用背景海报虚化填充
- Android TV：不显示导航栏，首页直接横向卡片流 + DPAD 焦点环

## 3. 逐页规格

### 3.1 首次启动 · 服务器配置页

**为什么单独成页**：客户端不含任何默认地址（`02` 文档安全约束），必须由用户填写。

```
┌──────────────────────────────────────────┐
│                                          │
│            [ Logo 72×72 ]                │
│              MoonTV 客户端                │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ 服务器地址                          │  │
│  │ https://____________________        │  │
│  │ 例：https://tv.example.com          │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────┐                          │
│  │ 测试连接    │  ○ 连接中… ✓ 可用        │
│  └────────────┘                          │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │            下一步                  │  │
│  └────────────────────────────────────┘  │
│                                          │
│  高级 ▾   （超时、自定义 UA、允许自签证书）│
└──────────────────────────────────────────┘
```

| 交互 | 规格 |
|---|---|
| 输入即时校验 | 必须是 `http(s)://` 开头；去尾部 `/`；不支持 IP+端口外的非法字符 |
| 测试连接 | `GET {base}/api/server-config`（该路径**免鉴权**，见 `01` 第 7 节） |
| 成功判定 | HTTP 200 且响应为 JSON；记录 `serverVersion` 用于兼容性提示 |
| 失败文案 | 超时→"无法连接，请检查地址或网络"；404→"该地址不是 MoonTVPlus 服务"；证书错误→"证书无效，可在高级中允许自签" |
| 不做的事 | **不预填任何地址**，不提供"官方服务器"入口 |

### 3.2 登录页

后端支持 `localstorage` / `kvrocks` / `redis` 等存储模式，token 体量与字段不同，客户端需按响应自适应。

```
用户名（可选，localstorage 模式隐藏）  [__________]
密码                                  [__________]
                                      [  登 录  ]
                                      □ 记住我
```

- 提交：`POST /api/login` body `{username?, password}` → 成功返回 `{ok:true, token?, auth?}` 并 `Set-Cookie: auth=...`
- **必须持久化整个 cookie**，不只是 token（`middleware` 只认 cookie `auth`）
- 失败：`429` → "尝试过于频繁，请 N 秒后重试"（后端有 fail2ban）；`401` → "密码错误"
- 记住我 = 保存 cookie 到安全存储；不勾选则仅本次会话

### 3.3 首页

```
┌ 继续观看 ────────────────────────────────┐
│ [ 16:9 缩略图 + 进度条 42% ]  [ 缩略图 ]   │
└──────────────────────────────────────────┘
┌ 今日更新 ────────────────────────────────┐
│ [海报2:3] [海报] [海报] [海报] [海报] →   │
└──────────────────────────────────────────┘
┌ 热门推荐 ────────────────────────────────┐
│ 网格 2列(手机) / 4列(平板) / 6列(桌面)     │
└──────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 继续观看卡 | 16:9 图 + 底部 3px 进度条 + 右上角"续播 12:34"；点击**直接进播放页并 seek** |
| 海报卡 | 2:3 圆角 14，加载中显示主色 8% 骨架屏；hover（桌面）上浮 4px + 描边高亮 + 显示"▶ 播放"浮层 |
| 横向轨道 | 桌面端 hover 出现左右箭头；移动端惯性滚动 + 右缘渐隐遮罩 |
| 空态 | "还没有观看记录，去发现页逛逛" + 跳转按钮 |
| 数据来源 | `GET /api/searchhistory`（历史）、`GET /api/douban-recommendations` / `advanced-recommendation`（推荐）、`bangumi`（今日更新） |

### 3.4 搜索页

- 顶部搜索框常驻，输入 **300ms 防抖** 后请求 `GET /api/search?q=`
- **搜索中不遮屏**：保留上一次结果，顶部一条 2px 进度条
- 结果按 `source_name` 分组折叠：同一作品多个源，默认展开权重最高的源（`weight` 字段）
- 每条结果：海报 + 标题 + 年份 + `vod_remarks`（如"全80集"）+ 源标签
- 空结果："没找到「xxx」，试试别名或原名" + 热门词建议
- 历史：本地存最近 20 条，可单条删除 / 清空

### 3.5 详情页

```
┌───────────────────────────────────────────────────┐
│  [背景：海报高斯模糊 + 暗化遮罩]                    │
│                                                   │
│  ┌────────┐  标题（display）                       │
│  │ 海报    │  2023 · 日本 · TV · 28集               │
│  │ 2:3    │  ★ 9.2 豆瓣                          │
│  └────────┘  [ ▶ 继续观看 第12集 ]  [ ☆ 追番 ]     │
│                                                   │
│  简介（默认 3 行，点击展开）                         │
├───────────────────────────────────────────────────┤
│  选集   源：哔哩哔哩 ▾                              │
│  [1][2][3][4][5][6][7][8]…  ← 横向滚动             │
│  当前集高亮为主色实心                                │
├───────────────────────────────────────────────────┤
│  相关推荐（横向轨道）                                │
└───────────────────────────────────────────────────┘
```

| 交互 | 规格 |
|---|---|
| 数据 | `GET /api/detail?id={id}&source={source}` |
| 选集 | 点击直接进播放页，不返回详情页；**长按/右键**显示"从这里开始播" |
| 切源 | 右上角下拉；切源后保持当前集号（能对上则对上，对不上回第 1 集并 toast 提示） |
| 海报到详情 | Hero 共享元素动画，时长 300ms，`Curves.easeOutCubic` |
| 剧集数 > 50 | 横向滚动 + 顶部显示"共 N 集"，避免一次渲染 500 个 chip（用 `ListView.builder`） |

### 3.6 播放页（核心）

**布局两段式**：默认极简 → 点击展开。

```
默认态（3 秒无操作后进入）
┌───────────────────────────────────────────────┐
│                                               │
│                 视频画面                       │
│            （弹幕叠加在此层）                   │
│                                               │
│  ─────────────●─────────────────────  12:34 / 24:00│  ← 细进度条，始终可见
└───────────────────────────────────────────────┘

展开态
┌───────────────────────────────────────────────┐
│ ← 返回            标题 · 第12集          ⋮     │  ← 顶部栏，渐隐渐显
│                                               │
│                                               │
│        ◀◀ 10s      ▶/⏸      ▶▶ 10s            │  ← 中央控制
│                                               │
│  ─────────────●─────────────────────           │
│  00:12:34                          00:24:00    │
│  ▶  🔊 ────  「弹」  ⚙   ⛶                    │  ← 底部工具条
└───────────────────────────────────────────────┘
```

| 交互 | 规格 |
|---|---|
| 显示/隐藏控制层 | 点击画面切换；**3 秒无操作自动隐藏**；鼠标移动即显示（桌面） |
| 双击 | 左侧双击 ←10s，右侧双击 +10s，中央双击 播放/暂停（移动端惯例） |
| 横滑 | 移动端：左右滑 seek（带方向指示气泡），上下滑左侧亮度 / 右侧音量 |
| 缩放 | 双指捏合 → 画面填充模式（适应/填充/拉伸/16:9 裁切） |
| 倍速 | 长按画面 → 2.0x 临时加速，松开恢复 |
| 弹幕按钮 | 单击 开/关；**长按** 打开弹幕设置面板 |
| 全屏 | 桌面 F11 / 双击标题栏；移动端横屏锁定 |
| 快捷键（桌面） | `Space` 播放暂停 · `←/→` ±5s · `↑/↓` 音量 · `F` 全屏 · `D` 弹幕 · `Esc` 退出 |
| 进度条预览 | hover 显示时间气泡；若已生成缩略图则显示预览帧（v2 再实现） |
| 起播 | 记住上次音量/倍速/弹幕开关；**不自动续播超过 95% 的进度**（视为看完，从头播） |

**弹幕叠加层**
- 三层轨道：滚动（右上→左）、顶部固定、底部固定
- 滚动弹幕轨道数 = `floor(可用高度 / 行高)`，行高 = 字号 × 1.6
- **防遮挡**：底部 20% 与顶部 15% 区域禁止滚动弹幕进入（避开字幕）
- **轨迹记忆**：同一 `用户Hash` 的弹幕优先复用上次轨道（减少"同一人刷屏跳动"）
- 同屏上限 80 条，超出则不渲染（不是延迟渲染，直接丢，避免堆积）
- 透明度、速度、字号、显示区域、关键词屏蔽（正则）均可调，配置持久化

### 3.7 追番 / 新番表

- 数据：`GET /api/bangumi`（周表）；按周一~周日 7 个 section
- 卡片显示：封面 + 标题 + 第 N 集 + 更新时间
- 点击进详情；已追番的显示高亮边框
- 空态："本周暂无数据"（数据源可能为空，不能报错）

### 3.8 我的（收藏 / 历史 / 下载）

三个 Tab：
- **收藏**：`GET /api/favorites` 网格；左滑（移动）/ hover 显示删除
- **历史**：`GET /api/searchhistory` 列表，按日期分组；右滑删除单条；顶部"清空"
- **下载**：本地任务队列（v1 可只做"标记想看"，真下载放 v2）

### 3.9 设置

分组列表（桌面端右侧内容区，移动端全屏 push）：

| 分组 | 项 |
|---|---|
| 服务器 | 地址（可改）、连接测试、退出登录 |
| 播放 | 默认清晰度、默认倍速、硬解/软解、自动连播、跳过片头片尾（秒） |
| 弹幕 | 开关、透明度、字号、速度、显示区域、屏蔽词、**自动加载源数上限**、是否允许记忆优先 |
| 外观 | 主题（跟随系统/亮/暗）、首页布局密度、动效开关（省电模式关闭动效） |
| 关于 | 版本、开源许可（含 NipaPlay-Reload 的 MIT 声明）、日志导出 |

**"关于 → 开源许可"必须包含**：本项目的许可证、上游 MoonTVPlus 的 CC BY-NC-SA 4.0 声明、参考项目 NipaPlay-Reload 的 MIT 声明。这是法务要求，不是可选装饰。

## 4. 动效规格

| 场景 | 时长 | 曲线 |
|---|---|---|
| 页面切换 | 280ms | `easeOutCubic` |
| 海报 → 详情 Hero | 300ms | `easeOutCubic` |
| 控制层显隐 | 180ms | `easeOut` + 透明度 0→1 |
| 卡片 hover 上浮 | 140ms | `easeOut` |
| Bottom sheet | 260ms | `easeOutQuint` |
| 弹幕淡入（首条） | 400ms | linear |
| 骨架屏微光 | 1200ms 循环 | linear |

**省电/低端机降级**：设置中"减弱动效"开启后，Hero 与页面转场退化为淡入淡出（120ms），模糊半径减半。Android 内存 < 3GB 时默认开启。

## 5. 双端适配矩阵

| 维度 | Windows (Tauri/Flutter Desktop) | Android |
|---|---|---|
| 导航 | 左侧 Rail 展开 | 底部 NavigationBar |
| 输入 | 鼠标 hover + 滚轮 + 快捷键 | 触摸手势 + 长按 |
| 窗口 | 可缩放，最小 1024×640，记忆尺寸 | 横屏播放页强制横屏，退出恢复 |
| 全屏 | 原生窗口全屏 | 沉浸式（隐藏状态栏/导航栏） |
| 后台播放 | 不适用 | 需前台服务（`mediaPlayback` 类型），否则息屏被杀 |
| 返回键 | `Esc` / 窗口关闭确认 | 物理返回：播放页先退全屏 → 再退页面 |
| 安全区 | 无 | 刘海/挖孔避让（`SafeArea`） |
| 权限 | 无 | 网络（必）、通知（前台服务需）、存储（下载，v2） |

## 6. 验收标准

| # | 项 | 通过条件 |
|---|---|---|
| U1 | 双主题 | 亮/暗均可读，无灰糊、无白字压白底 |
| U2 | 玻璃层 | 任意页面截图，玻璃卡片可辨认出背景模糊（非纯色块） |
| U3 | 播放页极简 | 3 秒后仅剩进度条，其余元素完全淡出不可点 |
| U4 | 手势 | 双击左右各跳 10s，误差 < 1s |
| U5 | 键盘 | 桌面端 7 个快捷键全部生效，无冲突 |
| U6 | 焦点 | Android TV 上 DPAD 可遍历所有可点元素，焦点环清晰可见 |
| U7 | 空态 | 断网/无数据时每页都有文案，不出现白屏或无限 loading |
| U8 | 大列表 | 500 集剧集滚动 60fps 不掉帧 |
| U9 | 返回 | Android 返回键在播放页/详情页行为符合第 5 节矩阵 |
| U10 | 许可 | 关于页含三方许可声明，`CREDITS.md` 已列 NipaPlay-Reload |

## 7. 给实现方的三条硬约束

1. **不要照搬参考项目的配色与图标库**——学结构与交互节奏，视觉要自建（token 见第 1 节）。否则成品会被一眼认出是换皮。
2. **玻璃拟态先做暗色**——暗色下层次最容易做对，亮色是它的弱项，必须单独调描边与填充透明度。
3. **播放页是产品的全部**——首页丑一点用户能忍，播放页卡一下用户就卸载。资源优先投在播放器与弹幕渲染上。
